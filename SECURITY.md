# Sicherheitshinweise

Sicherheitslücken in den SDKs, Plugins oder im Dienst bitte **nicht** als öffentliches Issue melden, sondern per E-Mail an service@urbanstudio.de (Betreff „Security: EMPEDIAcaptcha“). Wir antworten in der Regel innerhalb von zwei Werktagen.

Dieses Repository ist ein Spiegel; Korrekturen werden im Hauptrepository eingepflegt und hier veröffentlicht.
